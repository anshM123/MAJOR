# Status of the Einstein-gravity programme (living summary; updated as results arrive)

Last update: 21 Nov 2026. **Authoritative statement: `RESULT_D_STATEMENT.md` (read its post-review box first).** **Result D is a conditional result, accepted as the
foundational gravitational result of the programme (user decision, 21 Nov 2026):** with the fixed functional Ω^EE (NF02 weights, min-norm gauge), per-state positivity
on heavy blocks implies √(t₄²+α_T²) ≤ 2.89·10⁻⁸ at Δ_g = 1000 and ≤ 3.13·10⁻⁶ at Δ_g = 300 [D]; positivity is computed on the EE block near the gap for even
J ≤ 40, J = 48, odd J ≤ 31 at Δ_g = 1000 and is model-level/open elsewhere (named computational hypotheses H_M, H_OO, H_R, H_edge, H_LJ). Not a theorem; Δ_g = 100
not established. The previous header line follows for history:
CFT3 data — is not established.** This file lists every link of the chain with its status.

## Target

For CFT3s with large `c_T` and all higher-spin single-trace operators above `Δ_gap`: a rigorous bound on the
non-Einstein cubic graviton coupling of the form `|ĝ_3|² ≤ (function vanishing as Δ_gap → ∞)`, with explicit
assumptions and error terms, valid in the curved AdS4 regime. The flat-space analogue is a physics-level
derivation with numerically checked positivity (arXiv:2201.06602 (4.4)).
