# Scaled integer sliver verifier — partial result, not full closure

Base: `sliver_coupled_cap_certificate_2026-11-26.zip`, including authenticated compact coefficient data (SHA256 811e15cdd95319309edf64f5cf862bb674f43fbc73f551a002577c4b56b1ee06), formula, cap proof, analytic approximation and tail bounds. All of those inputs are retained, conditional on the upstream angular identity and spectral certificates.

Two new complete both-channel norming scans passed on c=[.35,.4462] and [.4462,.5305]. These are 2,452,700 actual scalar evaluations. The lower bounds are recorded as exact rationals in the two ledgers. `VERIFY_EXECUTED.py` checks the archived node grids, scale schedules, counts and ledger arithmetic; it does not rerun every scalar recurrence. The external repository ledger has separate coverage through c=.56 in both channels. The top-cell SIMD scan was stopped unfinished and is NOT part of the executed proof.

Scaling: for each ladder factor r_j, compute a common exact upper bound R_j=max|r_j| over both channels and the four coupled-cell corners; the fractional-linear extrema justify the bound across the cell. Track a dyadic upper product at scale 2^100, rounding upwards, and double it when <=1/2 to obtain nondecreasing integer shifts s_j. Then 2^s_k product_{j<k}|r_j| <= 1. The scaled backward recurrence represents v_k=2^(180-s_k)V_k, with transition 2^(s_(k+1)-s_k) r_k. Each local error in integer units propagates to the output with weight <=1. The source uses truncated signed integer arithmetic; fewer than 10 units of error per step cover all local coefficient, dressing and division roundoffs. The compact table's coefficient radii are separately charged in the driver. All remaining sign and normalization arithmetic is exact rational, as in the base certificate.

Reproduce: extract the base package, place the delta files in its certificate directory (retaining `coeff_compact60.txt`), run `python verify_all.py` to recheck the inherited analytic preflight, then `g++ -std=c++17 -O3 scalar_scaled.cpp -lgmpxx -lgmp -o scalar_scaled`. Run `python norm_driver_scaled.py cell_3500_4462.json` and `python norm_driver_scaled.py cell_4462_5305.json`, then `python VERIFY_EXECUTED.py`. The same scalar driver accepts the remaining base cell configuration files. A completed scan must have both exact positive lower bounds before being counted as coverage. Preflight and sampled positive values are insufficient. No full-sliver claim is made.
