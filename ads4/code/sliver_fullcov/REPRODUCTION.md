# Reproduction of the signed angular-action certificate

This package contains the exact signed checks for the target sliver, their compact coefficient table, the earlier local direct checks needed at the lower endpoint, and the complete continuum norming proof in `sliver_merge/PROOF.md`. The original moment generation and retained physics identities remain dependencies of the prior full-band reduction package and repository. No physical result is inferred solely from a floating-point scout or a preflight grid.

## Fast audit of the completed certificate

From this directory, with Python 3, NumPy and SciPy installed:

```sh
python check_ledgers.py
```

This rechecks the analytic error sums, exact rational node construction, pole gaps, all coefficient transfers for the direct low cells, dyadic scaling schedules, recorded node counts, reference Bernstein coefficients, final rational inequalities and interval union. It is intentionally different from rerunning all scalar sums. It exits unsuccessfully if any expected interval is missing, a sign fails or an input mismatch is found. The final assembled ledger is `sliver_merge/FULL_COVERAGE_LEDGER.json` only when the exact union check passes.

## Independent replay of every signed calculation

On a system with a C++17 compiler, GMP development libraries and 64-bit unsigned long:

```sh
python replay_scalar.py --jobs 4
```

This compiles the portable integer implementations and compares each complete archived scalar shard byte-for-byte against its output. On a machine supporting AVX512IFMA, `--simd` uses the faster corrected integer-division SIMD implementation for the new grids. The portable implementation works without those instructions. The number of jobs can be adjusted. Use `--new-only` or `--match cell_8936_9000_r0` for a targeted replay. These are computationally substantial checks. The included exact per-node regression comparisons validate representative subsets of the SIMD implementation against GMP, not merely the projected decimal endpoints.

## Authenticate against the original corrected coefficients

The signed checks use the exact compact enclosures and the retained prefix of the long table. To verify their provenance from the original 3,000-digit `coeff_long_17200.txt` in the prior full-band reduction package:

```sh
python authenticate_original.py /path/to/coeff_long_17200.txt
```

This checks the original SHA256, all retained prefix rows and enclosure containment for every one of the 17,201 compact pairs. The old direct cell below c=.268 uses the separately retained `old_coefficients.txt` and its own verified action-level allowance. We additionally charge the common conservative 10^-14 allowance in the merged ledger.

The original raw moment generator, the seed-substitution proofs and the physical angular-action identity are not independently regenerated by this replay. They are explicitly retained inputs, not newly established consequences of the sign scan.
