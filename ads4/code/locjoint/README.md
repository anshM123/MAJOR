# Standalone joint beta–Cauchy localization checker (Loc-Joint)

**Scope:** the connection-series truncation remainder, not full positivity of the finite-mass action. Parameters: `J0=1500` (connection truncation order, NOT physical spin), `a>=998`, `s=1,9`, `0.012<=t=a/N<=0.26`, `p=3,4`, real frequency. The physical band `0.8<=L<=3.65` lies in this t range. The geometry proof is independent of physical spin and does not enumerate it.

## Reproduction

Requires Node.js >=18 and no third-party packages. Run from this directory:

```sh
node check_joint.js output > rerun.log
python3 verify_cell_list.py output
```

The included `run.log` and `output/` were generated by a fresh execution of the provided source in this chat. Node version: v22.16.0. The checker uses BigInt with scale `10^16` throughout its numerical proof; no binary floating-point transcendental evaluation. Ordinary JS numbers are used for loop indices, counts and elapsed time only. The CSVs contain the full joint partitions, not a sample or only worst cells. `summary.json` records every t slab and its maxima. All CSV fields except slab/beta/angle indices are signed integers in units of `10^-16`; `NA` means that a geometric-tail bound was not used. `log_FT` is the full-function plus truncated-series bound, `log_tail` the directly summed geometric tail, `log_weighted` their minimum plus log beta and angular probabilities. The phase columns are in radians. `verify_cell_list.py` checks the archived partition, arithmetic combination and recorded maxima independently of the JS file; it is not a second implementation of the analytic envelopes.

The archive includes an optional input-inventory checker:

```sh
python3 verify_spectral_inputs.py /path/to/MAJOR
```

It checks the actual repaired JSON and NF02 polynomial files if available in your repository checkout. The joint-cell program itself does not need these files. The supplied `spectral_inputs.json` records the checks performed on repository data via the connected GitHub reader. The EPSW error and cutoff certificate are retained inputs, not regenerated by this package. See the distinction below.

## Analytic bridge from cells to the kernel

These arguments justify the inequalities evaluated by `check_joint.js`. They are written separately from the arithmetic to allow independent mathematical review.

### 1. Physical parameters and normalized positive measures

Let `n=J_phys-b`, `N=n+a`, `s=2b+1`, `D=N(N+s)`, `h=1/D`, `c=n(n+s)/D`, `d=1-c`, `t=a/N`, `rho=1-t`. Then `tau=1/T<=h<=t^2/a^2`, where `T=D+b(b+1)`. The exact relation is

```
d=t(2-t+s/N)/(1+s/N).
```

For `a>=998`, `s<=9`, the right-hand side increases with t at fixed a. Also `d<=2t` and `d>=t(2-t)/(1+9t/998)`. These show `exp(-3.65)<=d<=exp(-0.8)` implies `0.012<t<0.26` (the bounds have strict slack).

For any analytic `F` in the unit disk, the exact beta–Cauchy identity is

```
L(F) = E_B [ [z^n] (1-z)^(-a-1) F(B z) ] / binom(N,n),
B ~ Beta(n+s,a).
```

It follows term by term since the binomial coefficient ratio is `n_falling(k)/N_falling(k)` and the beta moment is `(n+s)_k/(N+s)_k`. On the circle `|z|=rho`, taking absolute values gives `|L(F)| <= K0 E_B E_W |F(B rho exp(i theta))|`, with `W(theta)` the normalized weight `|1-rho exp(i theta)|^(-a-1)`. Here

```
I_W=(1/(2*pi))*integral_{-pi}^pi |1-rho exp(i theta)|^(-a-1) dtheta,
K0=rho^(-n) I_W / binom(N,n) < 1.6.
```

For the last inequality use `sin(theta/2)>=theta/pi` for `0<=theta<=pi`, extend the resulting integral to infinity, and obtain `I_W <= t^(-a) sqrt(pi) Gamma(a/2)/(4 sqrt(rho) Gamma((a+1)/2))`. Stirling bounds for real positive arguments give `binom(N,n) rho^n >= t^(-a) exp(-1/(6a))/sqrt(2*pi*a*rho)` because `n>=a` on this domain. The gamma-ratio bound `Gamma(x)/Gamma(x+1/2)<=sqrt(x+1)/x` then gives `K0<= (pi/2) sqrt(1+2/a) exp(1/(6a))<1.6`.

### 2. Joint cell probabilities

Set `v=1-B`, `x=sin(|theta|/2)`, `z=(1-v)(1-t) exp(i theta)` and `r=|z|`. The independent measures in v and x allow multiplication of upper probability bounds.

For `m=a/(N+s)`, use

```
I(v;m)=log(m/v)+(1/m-1) log((1-m)/(1-v)).
P(V>=v) <= exp(-a I(v;m)) if v>=m,
P(V<=v) <= exp(-a I(v;m)) if v<=m.
```

This is obtained by applying the exponential Markov inequality to `(1-v)X-vY` with independent gamma variables of shapes `a` and `n+s`, and optimizing the exponential parameter (negative for the lower tail). On a t slab, `t_lo/(1+9 t_hi/998)<=m<=t_hi`. The derivative of I with respect to m is `-log((1-m)/(1-v))/m^2`. Thus the code takes the safe endpoint for the upper or lower tail; if the v cell may contain the mean, the bound is one. Run A deliberately omits the lower-tail estimate.

The angular tail bound follows by lower-bounding `I_W` on `0<=theta<=t/sqrt(a)` and upper-bounding the numerator on `|theta|>=theta0`:

```
P_W(|theta|>=theta0) <= pi sqrt(a)/t * exp((a+1)/(2a))
  * (1+4(1-t)x0^2/t^2)^(-(a+1)/2).
```

Set `k=log(1+4(1-t_hi)x0^2/t_hi^2)`. If `k<1/998` use probability one. Otherwise the bound with `sqrt(a)` times the decaying exponential is decreasing in a; use `a=998`, `pi sqrt(998)<100`, `(999)/(1996)<0.502` and the lower endpoint of t in the prefactor. Log probabilities are capped at zero. Cell mass is at most the product of the two tail bounds.

### 3. Phase geometry

Use `q=|1-z|`, `A=|arg(1-z)|`. For `x=sin(|theta|/2)`,

```
q^2=(1-r)^2+4 r x^2,
A=atan(2 r x sqrt(1-x^2)/(1-r+2r x^2)).
```

The enclosure `q_lo` uses `(1-r_hi)^2+4r_lo x_lo^2`, capped at one. The upper bound uses convexity in r and monotonicity in x, at the two r endpoints and upper x endpoint. The arctangent numerator and denominator are enclosed separately. All endpoint products are rounded in the safe direction.

For the full conical function ONLY, use the small Cauchy radius `delta=t_lo/100`. For any `zeta` in this disc, `|zeta|<=R=r_hi+delta<1`, `Re zeta>= min(r_lo*(1-2 x_hi^2),r_hi*(1-2 x_hi^2))-delta`. Then

```
|Im beta(zeta)| <= atan(sqrt(2*(R-Re_zeta_lower))/(1-R)),
beta(zeta)=2 atanh sqrt(zeta).
```

This follows from the exact formula with `R=|zeta|`, before enclosure. Run A uses the global `pi/2` phase cap instead. Neither the connection tail nor the truncated sum is enlarged. In particular `arcsin(|z|)` bounds `|arg(1-z)|`, NOT the full conical phase.

### 4. Connection coefficients, including zero frequency

The two branches have prefactors `B(±nu)=Gamma(±2i nu)/Gamma(1/2±i nu)^2`, powers `(1-z)^(j-p+1/2∓i nu)`, and `c_j(nu)=(1/2-i nu)_j^2/((1-2i nu)_j j!)`.

For real nu, put `X=j+1`, `y=nu^2`. The modulus of the consecutive coefficient ratio is `((X-1/2)^2+y)/(X sqrt(X^2+4y))`. Its derivative in y changes sign at most once, from negative to positive, so the maximum on `[0,V^2]` occurs at an endpoint. Accumulating logs yields the ceiling constants C=547,570,630 for V=999,1040,1150 respectively. For `j>=1500`, the ratio is at most one on `0<=nu<=1150`. Indeed the difference of the squared denominator and numerator is

```
2 X^3 + (2y-3/2) X^2 + 2X(y+1/4) - (y+1/4)^2.
```

It is concave in y, positive at zero, and positive at `y=1150^2` for `X>=1501` since `X^2(2y-3/2)>(y+1/4)^2` (checked exactly in source).

For `nu>=1/4`, the standard gamma identity `|2B(nu)|^2=coth(pi nu)/(pi nu)` gives `2|B|<2`. **The zero-frequency pole cannot be bounded branch by branch.** For `0<=nu<=1/4`, cancel it first: define `E(w)=Gamma(1+2iw)/Gamma(1/2+iw)^2`. For the branch function `Phi(w)` (including the dressing), the paired sum is `[E(nu)Phi(nu)-E(-nu)Phi(-nu)]/(2i nu)`. It is bounded by the derivative supremum of `E Phi` on the real segment, and by eight times the supremum on its radius-1/8 discs, including at nu=0. On these discs `|Re w|<=3/8`, `|Im w|<=1/8`, and `|E(w)|<26`: use `|Gamma(x+iy)|<=Gamma(x)`, the gamma modulus product `|Gamma(x+iy)|/Gamma(x)>=exp(-y^2(1/x^2+1/x)/2)` for the denominator with `x>=3/8`, and `Gamma(x)>=e^-1/x` from the integral on `[0,1]`. The numerator is bounded by `4/3+2/e`, denominator gamma factors by `(8/5)e^(-1-11/16)` each. For these discs the complex ratio of c coefficients is at most one, because with `X=j+1` the difference between `X(X+2 Im w)` and `|X-1/2-iw|^2` is `X-(1/2-Im w)^2-(Re w)^2>0`. Thus `|c_j(w)|<=1`. The powers incur at most `q^j q_lo^(-4) exp(V A)` on each cell. All of the estimates below admit the common prefactor 208 for these paired small-frequency branches, so they also hold at nu=0. This closes the removable-pole issue implicit in the original logs without needing new cell boundaries.

### 5. Exact dressing and envelopes

For `mu=j-p+1/2 ∓ i nu`, apply the actual operator

```
D_b = z(1-z)/2 * d_z^2 + ((7/2-2b)z+1/2)*d_z + 9/2-b(b-1).
D_b(1-z)^mu = (1-z)^mu [mu(mu-1)z/(2(1-z))
  -mu((7/2-2b)z+1/2)/(1-z) + 9/2-b(b-1)].
```

This implies the envelope `1+tau[r M(M+1)/(2q)+(4.5r+0.5)M/q+8]` where `M=j+p+V`. Since `q>=t` and `tau<=t^2/a^2`, use `tau/q<2.7e-7`, `tau<7e-8`, `r<=1`. For `j<J0` the envelope is <3. Including the prefactor 208 above, and 1500 terms, the truncated sum is bounded by

```
exp(C+16+V*A) * max(1,q_hi)^J0 * q_lo^(-4).
```

For the infinite tail, sum the quadratic in `j=J0+k` with the three geometric sums `S0=1/(1-q)`, `S1=q/(1-q)^2`, `S2=q(1+q)/(1-q)^3`. The prefactor is at most 208 times

```
(1+8 tau) S0 + (tau r/(2q))[(M^2+M) S0+(2M+1) S1+S2]
 + (tau(4.5r+0.5)/q)(M S0+S1),   M=J0+p+V<=2654.
```

For `q<=0.99` this is less than `exp(15)`; for `q<=0.999` it is less than `exp(20)` (substitute `S0<=100 or 1000`, `S1<=10000 or 1000000`, `S2<=2000000 or 2000000000`). Thus the logarithmic tail envelope is `C+15 or C+20 + V*A+J0*log(q_hi)-4 log(q_lo)`. It covers p=3,4 and both b, including paired small-frequency branches. The p=4 action does not need dressing but bounding it with this larger envelope is harmless.

For the full `F_{p,nu}`, Mehler's integral gives `|P_{-1/2+i nu}(cosh beta)|<=(pi/2)exp(nu |Im beta|)`. This follows by integrating along `beta*s` and applying `|sinh w|>=(2/pi)|w|` in the relevant strip to the two factors of `cosh beta-cosh(beta*s)`. On the small Cauchy disc, `|1-zeta|>=0.99 q`; and `tau/delta^2<=10000*(1.12)^2/998^2<0.013`. Cauchy's derivative estimate bounds the dressing multiplier by `1+2tau/delta^2+5tau/delta+8tau<1.03`. Together with `(0.99)^(-4)` this gives the full-function envelope `exp(2+V E) q_lo^-4`, where E is the local conical phase upper bound (run A safely uses `exp(4+V*pi/2)`). Adding this to the truncated sum costs a further log factor at most 1 (since `log 2<1`). The checker uses the minimum of the full-plus-truncated and direct-tail bounds whenever the latter is available.

### 6. Directed arithmetic

The logarithm routine reduces a positive rational argument to `[1,2)` by powers of two, then uses `log r=2 sum_{k>=0} ((r-1)/(r+1))^(2k+1)/(2k+1)`. After degree 39 the omitted tail is below `2*10^-16` (the transformed argument is <=1/3); every operation in the retained sum is outward-rounded. The enclosing ln 2 constants are 0.6931471805599453 and 0.6931471805599454. Arctangent uses alternating odd-power partial sums, with last terms of degree 45 and 47 for the upper and lower bounds, reduced to argument <=1/2 using reciprocal and pi/4 identities. The enclosing pi constants are 3.1415926535897932 and 3.1415926535897933. Integer square roots are used with floor/ceil. The arithmetic asserts exact cell counts and strict budgets; no empirical tolerance is added to make a cell pass.

## Spectral assembly and limitations

The previous claimed bound `E_rho,2+E_rho,3<exp(-46)` uses the following retained input data from the existing repo:

- `ads4/prl/data/k2/k2_continuum_D_1000_rep.json` (the repaired weight, not the unrepaired JSON); actual checked Gaussian coefficient absolute sum <1,212,961+1, hence <1.22e6, centers <1029, widths in (0.449,0.901), three logarithmic coefficients of modulus <1. These use binary64 values as the repo does. See `spectral_inputs.json` and the optional inventory checker.
- `ads4/prl/data/nf02_psi.json`: both polynomial coefficient l1 norms after division by k0 are <3e7, so each ideal absolute spectral mass (in p coordinates) is <3e7.
- The retained EPSW certificate (e.g. `ads4/code/epswcert/cache/ew_cert_1000_re_rep.txt`) gives `int|f-psi2|<=2.681358e-6` before cutoff. The retained cutoff bound in the tail audit is <1.333e-14 with weight exp(0.02 nu), hence also without that weight. These integral certificates are not re-executed here.

At `nu>=1040`, the repository's `ew_common.py` rational functions have the factored forms `QR_-=-32 z(2z+3i)(2z+5i)(2z+11i)/((2z-i)(2z-7i)(2z-3i)(2z+7i))` and `R_-=-2(2z-i)(2z+i)^2(2z+3i)(2z+5i)(2z+11i)/(z(2z-7i)(2z-3i)(2z+7i))`, with `z=nu-i`. On this line the first is <17 in modulus, and the second <183 nu^2 by elementary factor bounds. The cutoff theta is an integral of a Gaussian over a finite real interval, hence its modulus on this line is <=exp(0.01). Including both signed centers and the conjugate contribution, the inventory yields the conservative bound

```
|f_theta(nu)| <= exp(21-(nu-1029)^2/(2*0.901^2)) + exp(-nu^2/3).
```

For the logarithmic term, bound its polynomial-log prefactor by `10^6 nu^9` before multiplication by `exp((1-nu^2)/2+0.01)`; it is less than `exp(-nu^2/3)` on this range. The Gaussian Mills inequality gives `int_1040^infty |f_theta|<exp(-55)`. At 1150 the Gaussian bound weighted by `exp(pi nu/2)` has integral <exp(-7000) (complete the square or use the concavity of its log and the derivative at the endpoint). Above 1150 use the unsplit full kernel, whose bound is <exp(20+pi nu/2) here, rather than a truncated connection sum. The ideal k=3 spectrum ends at Lambda<999. Normalization gives `2/Lambda<1`, `tau Lambda^2<1` since t<=0.26, and w^3<=1. The total normalized absolute mass of the two spectra on [0,1150] is less than exp(19) by the retained EPSW and cutoff bounds. In A/B the kernel upper bound exp(-85) suffices. In C, the low and middle bands give at most exp(-168+19) and exp(-120+19), and the upper band at most exp(7-55). Adding the unsplit tail gives <exp(-46). This is a localization/truncation bound, not a bound on the signed main connection sum. The stated action error applies when the connection expansion is truncated only up to frequency 1150 and the unsplit high-frequency action is charged separately.
